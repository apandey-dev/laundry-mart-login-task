## 1. Project Title
**Laundry Mart - Modern Authentication & Login Interface**

## 2. Assignment Objective
To demonstrate mastery of modern CSS Flexbox layout techniques by designing a fully centered split-screen login card within a `100vh` viewport, aligning form controls and graphical assets cleanly without relying on CSS frameworks or margin/padding centering tricks.

## 3. Technologies Used
- **HTML5** (Accessible form controls and semantic containers)
- **CSS3** (Flexbox properties: `display: flex`, `justify-content: center`, `align-items: center`, `flex-direction: column`)

## 4. Features Implemented
- **100vh Flexbox Viewport Centering:** The outer `.page-container` occupies the full viewport height (`height: 100vh`) and centers the card vertically and horizontally using Flexbox.
- **Split-Screen Card Architecture:**
  - Left column: Branded vibrant blue container (`#00a6ff`) centering the 3D washing machine illustration (`laundry-machine.png`) via Flexbox.
  - Right column: Clean white card interior featuring a friendly header ("Hello Again! / Welcome back! we missed you!"), customized form inputs for email and password, a "Forgot Password" link, and a pill-shaped primary "Login" action button.
- **Member Registration Prompt:** Subtle footer link inviting unregistered users to create an account.
- **Pure HTML & CSS:** Completely handcrafted with `index.html` and `index.css`.
